## Why this is a bridge program, not a brute-force decoder competition

Historically demonstrated INSIDE solve sequences separate: source/order → geometry → payload selection → intermediate phrase/instruction → **independently specified consumer** → observable output. The CE backgrounds **already have one definite destination**, \`dat/534brn9653f9j8mmd/\`, whereas the foreground's operation and destination remain disconnected. Playdead's earlier printer-to-website-PDF pathway is externally documented in the [official Xbox Wire 2019 account](https://news.xbox.com/en-us/2019/01/03/unsolved-secret-in-inside/). The [iam8bit CE](https://www.iam8bit.com/products/inside-collector-s-edition) and [standalone physical edition](https://www.iam8bit.com/products/inside-ps4-physical-game) provide recoverable physical surfaces, but a scene appearing on both versions does not prove CE-exclusive registration.

The matrix of 162 operations × 82 consumer roles contains 13,284 **raw pairings**, most type-invalid or unsupported. Instead of test-spamming 13,284 pairings, require a **typed joining witness**: actual count/geometry, address space, alphabet, source version, named operation and independent acceptance criterion.

## Two different identifiability questions

Let \(U\) denote a *declared* set of physically compatible 108-symbol master strings, and let \(F\) be an **independently fixed operation** whose domain includes all masters in \(U\).

1. **Readout-identifiability:** number of distinct values in \(\{F(m): m\in U\}\). One distinct value means the output is fixed *inside that model family* without acquiring more stickers.
2. **Answer-identifiability:** an external, independently witnessed receptor \(C\) maps all values to the same verifiable answer: \(\{C(F(m)):m\in U\}\) is a singleton. This can occur when \(F\) itself varies, e.g., a masked-password entry or tolerant/semantic consumer.

The second is the meaningful user goal. Distinguish it from “all 108 symbols have been filled,” “the model was uniquely identified,” and “some reader looks pretty.” **Constancy of a derived feature across U5 is not proof of original authorial intent**, especially if U5's grammar was selected from the same observations. Repeat analyses on **U2=324**, **U3=108**, **U4=12**, **U5=10**, weaker source-motivated rivals and, when representational gauges matter, corresponding *physical* gauge variants. The U5 family is not universal.

## The 15-minute paper test before writing code

For **any** candidate bridge, complete:

1. **Native source object + date + hash:** identify exactly the original surface and whether contemporaries could access it.
2. **Input type:** one of \`108-bit H108\`, \`A–I nine tokens\`, \`Q4 nine trits\`, \`27-bit mask\`, \`9-bit address\`, \`3 trits\`, \`command\`, \`credential\`, \`image alignment\` or another explicitly described type.
3. **Authorial cue:** quote or depict the object that fixes operation and parameter *before outputs*. Distinguish physically observed cue from historical analogy and invented bridge.
4. **Unassigned freedoms:** orientation (8), bit polarity (2), reading order (2+), field division, mask registration, prefix/suffix, alphabet, phase, endpoint. Count combinations rather than hiding them.
5. **Full-completion computation:** \(|F(U2)|\), \(|F(U3)|\), \(|F(U5)|\), and where applicable gauges and rival models. Do **not** report a hand-selected completion as an inevitable message.
6. **Negative/synthetic controls:** ensure chosen scoring/reader recognizes a real positive control and does not routinely declare scrambled/complemented input a win.
7. **Decisive witness:** a real source-registered readout/accepted response or a frozen future physical prediction, not resemblance.
8. **Fail discipline:** label null as \`no source cue\`, \`type mismatch\`, \`source unavailable\`, \`bounded model contradiction\`, \`post-selection null\` or \`receiver rejected\`. This is more informative than “doesn't work.”

## Stop conditions and result standard

A source-native artifact specifying a nine-choice input, an exact 3×3 register, a 27-bit mask, three-channel RGB structure, or a genuine typed website/game input would justify a new finite bounded decoding trial. Merely finding a number 9 or a plausible word does not.

The strongest result obtainable without more stickers would be an **independently authored, reproducibly accepted answer that is invariant across every still-live compatible completion in more than one materially distinct structural family**. A less ambitious, still important result would be one source-registered transform that sharply distinguishes a one-pass selector from recursion using *already known physical symbols*. Both are meaningful closed-corpus research successes.

Original terminal/website backends may be unavailable, and the foreground may not encode a conventional cipher at all. Retain these as explicit alternatives rather than manufacturing a success by searching enough combinations.
