# Conjecture Lab CL-03 v2: Four cover monitors, four breached schemes?

_8 October 2026. Conjecture development, deliberately **not** validation. Source inputs: [Exp. 410 monitor inventory](../experiment-410-cover-monitor-source-inventory.md), [original saved Terminal41 state](../../archive/external/twinysam-inside-arg/terminal41.link/sys/printreqstatus_SD.html), [earlier CL-03](2026-10-08-first-sprint.md)._

## Working hunch

Pretend the clue-bearing reversible cover is a **status-board reminder of the ARG's four original completed printer schemes** rather than an external keypad for the sticker foreground. There are four visibly highlighted monitor screens on the cover (the exact number was checked in prior work), and the preserved Terminal41 status page labels exactly four breached schemes:

```
schem[0] PLANET
schem[1] LIFE
schem[2] PROBE
schem[3] CONDISCON
```

The cover's four previously identified display families are **planet**, **acorn/LifeDetected**, **graph**, and **login**.

A provisional association is easy to imagine:

| Native scheme | Possible cover reference | Evidentiary status |
|---|---|---|
| PLANET | planet monitor | High-level semantic anchor: genuine planet visual family |
| LIFE | partial acorn monitor | High-level semantic anchor: historical acorn -> LifeDetected puzzle |
| PROBE | graph-like monitor | **Invented thematic bridge**; graph is not verified as a literal probe display |
| CONDISCON | login-window monitor | **Invented thematic bridge**; logging in is not equivalent to connecting/disconnecting Joy-Cons |

These four slots are **not** independent binary matches; the number four and the two attractive source associations inspired the mapping. The latter two assignments might just as easily be wrong or unrelated. The cover is confirmed to be clue-bearing, but a solved one-to-one 4-scheme display is not established.

## Follow the assumption forward

If the mapping were authentic, the cover would **recap four original completed stages**, perhaps reminding players of the *operation types* rather than asking for a brand-new four-way answer. That would explain why the cover was also available to standard PS4 edition owners instead of having an intrinsically Collector's-Edition-specific interface.

Now introduce, explicitly as a second conjecture, that the CE's **foreground** is a distinct later metapuzzle. The sticker background supplies the real Terminal41 `534brn` destination; the four monitors supply *prior puzzle grammar*: planet = spatial rearrangement/Braille; Life = acorn/sequenced transform; Probe = source verification; CONDISCON = physical action. A hypothetical human solver might use the four operations in a particular order on the 108 foreground marks, then use the result on the damaged page or a historical website.

Three authorial bridges are still absent: a reason to map the two latter monitors to these two schemes, a reliable **order of operations**, and a readout/consumer linking the four operators to the foreground. Inventing those three bridges is permitted for model development but should not be mistaken for source-native registration.

The **absence of a fifth monitor** matters. A story in which the cover literally depicts a fifth scheme is unsupported. Similarly, the later June-2020 macOS printer message does not appear as an independently demonstrated fifth 2019 cover scheme. Chronology permits intentional foreshadowing but does not prove it.

## Sharp distinguishing questions

1. Does either original graph or login image visibly contain text, iconography or a code *specifically* identifying `PROBE` or `CONDISCON`? Exact source bytes and their historical scene roles would supply a genuine third/fourth link. Generic resemblance is insufficient.
2. Are the four monitors arranged spatially in the original Terminal41 `0,1,2,3` order, or another distinctly repeated order that can be measured without sticker outputs? Prior studies found no shared image transform; that negative remains in force.
3. Does the cover contain an **unaccounted fifth instruction** outside the monitor plane, perhaps the running figure, clock or other explicitly authored device? A loose resemblance does not suffice, and the current source inventory does not prove one.
4. Would a standalone-PS4 owner be able to solve the cover without CE stickers? If the answer is yes, the four-scheme recap could be independent of the foreground. If a source-fixed cover-to-foreground instruction exists, the theories could instead interact.

## Disposition

Keep as a **developed source-adjacent hunch**, with two real themed anchors and two invented semantic links. It is more economical than forcing nine stickers onto four screens by arbitrary position transforms, but it offers no new decoded foreground. In the next pass prioritize exact graph/login monitor content and the original `PROBE/CONDISCON` output artifacts. Preserve original high-resolution image bytes if recovered; do not manufacture them from current previews.
