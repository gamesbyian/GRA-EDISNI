## Provisional premise and what can actually be corroborated

Three separately observed **fours** motivate CX-C:

* The 108-symbol H108 foreground can be grouped into four consecutive 27-symbol quarters; this is a mathematical partition of the physical record, not an authenticated native parser.
* The clue-bearing reversible PS4 cover has four notably discussed monitors: planet, partial acorn, graph, and login families. Some elements match original source assets; all four do not demonstrably share a common source-to-cover transform (Experiments 410–412).
* A preserved historical Terminal41 status page names four breached schemes in index order: `schem[0] PLANET`, `schem[1] LIFE`, `schem[2] PROBE`, `schem[3] CONDISCON`. These are **four already breached requirements**, not a CE-decoding script or four calls to a function.

The independent community timeline places original printer schemes before the Collector's Edition stickers. The cover itself was supplied to standalone PS4 purchasers, not only CE sticker holders ([cross-edition audit](../cover-cross-edition-dependency-audit-2026-10-08.md)). Therefore: a cover-only puzzle is a real alternative, and the cover's existence is not evidence of CE coupling.

## Two conditional end-to-end walkthroughs

### C1. Standalone-cover retrospective puzzle (simpler source dependency)

1. **Observed:** Purchase standalone physical PS4 INSIDE; flip the advertised clue-bearing cover. No CE sticker required.
2. **Observed/historically attested:** Identify planet and partial acorn monitors, compare graph/login screens to corresponding in-game/source displays; recognize references to solved original puzzles.
3. **Invented bridge C1a:** Treat omissions or changed elements across original and monitor renderings as an instruction, not as artwork. The acorn is a plausible positive cue for *completion*; the other three monitors have not independently shown that same operation.
4. **Invented bridge C1b:** Read the differences or use the clock/running figure to impose an **unambiguous** order. Existing Experiment 412 found no common measurable transform, and 12:12 has no source-fixed role.
5. **Invented endpoint:** The resulting difference/sequence could indicate a known ARG location or offer a standalone clue. **No resulting message or coordinates presently exist**.

**Conditional deduction:** This model predicts a cover interpretation using only assets available to a non-CE owner. If one fully source-defined transformation unites the acorn crop and at least one other monitor, the cover could become an *operation keybook*. If no repeatable transformation exists, C1 can still be a visual recap instead of an encoded operation. That is a source-audience explanation, not a failed experiment.

### C2. CE four-quarter metapuzzle (more assumptions; develop, do not discard reflexively)

1. **Observed:** Collect H108 by serial, keeping unknowns unknown. Divide at residues 27/54/81 into Q1/Q2/Q3/Q4 (chosen four-quarter format).
2. **Borrowed analogy:** Use cover monitors as a keybook that points at four historical operations.
3. **Invented bridge C2a:** Map four source schemes to the four screen positions. PLANET↔planet and LIFE↔acorn are semantic anchors; the other **two** assignments remain arbitrary. Four screens to four schemes otherwise allow **4! = 24** bijections (only **2! = 2** if both anchors are assumed correct).
4. **Invented bridge C2b:** Interpret *abstract verbs* such as ordering, geometric reassembly, indexing/reading, and activating a receiver. A literal transfer is **type-incompatible**: each 27-mark quarter is neither a 36-wide Xbox printout, 32-line acorn raster, 24×25 iOS bitmap nor controller feedback channel.
5. **Invented bridge C2c:** Supply a typed adapter for **each** quarter, and a stage ordering. The Terminal41 numbers provide one historically known scheme order (PLANET→LIFE→PROBE→CONDISCON), but do **not** independently demand that the CE quarter order reproduce it. Without such an order cue, there are **4! = 24** quarter-to-stage alignments; with fixed two semantic associations the assignment and stage ordering are still separate choices.
6. **Invented endpoint C2d:** The abstract operations construct a compact instruction or partial target for an authentic receiving artifact (e.g., damaged `534brn` page). The actual foreground output type, receiver data structure, and foreground→source rule are currently absent.

**Conditional deduction:** The most economical viable four-stage *story* is a **typed instruction program**, not a literal re-run of four historic decoders. If the cover signals a real source-authored sequence of operations, it should specify (i) which structural dimension each step consumes, (ii) how 27 marks become appropriate input, and (iii) what stage output is retained for the next step. This is the missing discriminating evidence. No invented plaintext is treated as recovered.

### C3. Four-reference board with **no further CE endpoint** (mandatory control)

The cover may summarize the four already breached platform schemes. The foreground might independently be a stand-alone message, manufacturing control data, or an abandoned continuation. This model requires **zero cover→CE coupling**, agrees with standalone distribution, and avoids assuming a present-day printer website exists. It does not independently explain the foreground, so keep it as a control rather than declare the case closed.

## Structural preflight and failure scope

A typed composition normally requires `stage_{i+1}(stage_i(payload))`, with the former's output belonging to the latter's input domain. The four authentic historical operations have **different input types and output types**. Therefore **the literal same-four-decoder chain is not executable on 27-character quarters without adapters.** This is a type mismatch, not proof that Playdead could not have intended a new analogy or transformation.

Source cardinality and ordering are further constraints:

* 4×27 is arithmetically exact for H108, but the old printer layouts have 36×36 (Xbox), 32×32 (PC long rows), 24×25 (iOS), and live Switch controller actions. No source-authored 27-site operator has been identified from these precedents.
* No archived source orders **the four cover monitors as four commands**. Calling the scheme index order an instruction would create an unproved cover→scheme→quarter bridge.
* Cover **graph/login** references are recognizably in-game display assets; no independently verified graph=PROBE or login=CONDISCON instruction. Even the two apparent semantic matches cannot identify an output.
* The historical webpage printer accepted three known phrases before CE shipping; the four Terminal41 status slots are **not** proof of a fourth website PDF or a new CE password (Experiment 480).
* Experiment 412's negative search for a common source→cover transform remains unchanged.

No actual sticker combination or physical holdout was used to choose these associations. The narrow conclusion is a **failed literal typecheck** and an *unresolved* abstract program, not a disproved CX-C family.
