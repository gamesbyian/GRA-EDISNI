# CL-OPS-02: nine tail trits as a real 81-body instruction stream

*12 October 2026. DISCOVER + conditional DEVELOP. No CE decoder or authored opcode grammar is claimed.*

This continues [the Playdead operation-grammar program](2026-10-12-playdead-operation-grammar-brainstorm.md) by treating the final 27 slash/dot stickers as **nine three-way class-local commands**, not as 27 unrelated checksum bits. It differs from the earlier [simple per-bit checksum pilot](2026-10-12-playdead-operation-grammar-brainstorm.md#p2-is-each-tail-mark-a-checksum-of-three-body-marks), [class-local copy/reverse commands](2026-10-12-class-run-command-campaign.md), and [run-length streaming programs](2026-10-12-streaming-rle-instructions.md).

Source: the immutable 84-record, 66-distinct-residue [physical sticker CSV](../../data/observations.csv). The source has 54 observed slash/dash body sites (1-81), 12 observed slash/dot tail sites (82-108), and **42 unknown sites**. The experiment never fills an unknown from U2, U5 or other previous sticker models.

## Phase A: exact observation-only selector

In the last three consecutive nine-site frames, group the three positions bearing each A-I image class. Under the **conditional** one-slash-per-class assumption, the tail specifies one of three depths for each class. Physical evidence leaves the following depth options (zero based):

| A | B | C | D | E | F | G | H | I |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 0,1,2 | 2 | 0,1,2 | 1 | 0 | 1 | 0,2 | 2 | 2 |

There are precisely **3 x 3 x 2 = 18** physically compatible selector vectors. This is a conditional family, not 18 observed originals.

An economical literal program lets class j's selected depth operate identically on each of the three 27-position body quarters:

    output[q,j] = body[27*q + 9*selector[j] + j]
    q=0..2, j=0..8 (A..I)

Enumerate all 18 selectors. A position is *forced* only when every possible selection accesses the same **known physical glyph**, not when multiple alternatives merely share one plausible letter.

| Body quarter | 9-character output (unresolved = ?) | Forced |
| --- | --- | ---: |
| 0 | ?/-///?-? | 6 |
| 1 | ?/////?-? | 6 |
| 2 | ?-??//?// | 5 |
| **Total** | **17 of 27 known** | **17** |

A first quick handwritten version counted 18; it erroneously treated a two-symbol set slash-and-dash as if it were a single fixed mark. The script now asserts the exact 27 positions and correctly counts **17**, with ten unresolved. The result is *not* recognized plaintext or an authenticated printer/website input.

**Calibrating this observation:** in 5,000 seeded matched shuffles of the known slash/dash symbols within each of the original nine 9-site body frames, retaining the exact observation mask and per-frame symbol counts, **1,052/5,000** controls force at least 17 positions with the same selector options (21.04%). This partial output is therefore a **useful concrete receiver candidate**, not an unexpectedly strong correlation or decipherment.

## Phase B: nine-word *sequential* interpreter

Read the nine first-81 occurrences of each class as its own 3x3 body word. The initial class word is a free nine-bit state. Each subsequent class word is fully produced from the previous state by the *incoming class's tail trit*.

Freeze three simple source-geometric opcode dictionaries:

1. 0=identity, 1=rotate 90 degrees clockwise, 2=rotate 90 degrees counterclockwise;
2. 0=identity, 1=shift 3x3 rows down one, 2=shift rows down two;
3. 0=identity, 1=shift columns right one, 2=shift columns right two.

Test two independently available orders: alphabetic A..I and physical solved-mosaic IAB/CDE/FGH. Also test a *single global* slash/dash complement applied on every step or never. This gives **12 predeclared stream grammars x all 18 physically admissible tail vectors**. Only the first literal word can be chosen freely. Every subsequent word is actually generated by executing an instruction. In particular this is **not** an independent test that assigns a new literal word after every command.

Each opcode is a nine-bit permutation, possibly complemented. Composing a candidate program therefore expresses all nine class words in terms of the first nine root bits. Every observed physical body symbol constrains one of those bits. Summing the less common forced value for each root bit gives the exact minimum physical disagreement, without filling any unobserved sticker. A separate brute-force **512-initial-state interpreter** cross-checks the symbolic scorer.

| Class order | Rotation: no/yes invert | Row shifts: no/yes | Column shifts: no/yes |
| --- | --- | --- | --- |
| A..I | 17 / 16 | 14 / 17 | 18 / 16 |
| IAB/CDE/FGH | 17 / 14 | **13** / 19 | 16 / 16 |

**All twelve grammars have zero exact physical-sticker-compatible completions**, for **every** allowed one-hot tail vector. The best still contradicts at least **13 of 54 physically observed body symbols**. This is a clean exact negative for the frozen hypothesis, without needing any new stickers.

Against 500 seeded physical-mask-and-within-frame-count preserving shuffles, selecting the best of the same 12 models and 18 selector completions each time, **325/500** controls have a minimum conflict count at most 13 (65%). The already-falsified candidate is not unusually close to fitting the body.

Do not silently rescue this model with arbitrary per-step mutations, unlimited permutations or post-hoc codebooks. A true source-native operation or receiver would be needed to justify a materially different interpreter. This negative does not disprove the original ternary-machine conjecture, sparse selectors used only to read an independent artifact, or code streams with externally supplied instructions.

The new [dedicated CI workflow](../../.github/workflows/verify-ternary-tail-stream.yml) executes the script on PRs, checks frozen observed counts and controls, and independently enumerates all 512 possible initial literal words for one reference case.

Next steps should be **source-first**: find an original-game, cover, printer, or 534brn-page cue that fixes a genuine *input operation* or 3x9 readout. Our 17 fixed 27-output glyphs are now a compact conditional control for such a cue, while the full-word-rotation program is closed. Existing simple RLE, nine-digit lever, generic Braille and unconstrained bitmap fitting negatives remain valid and should not be rebranded.

**Conclusion:** the 27-tail/81-body separation supports a very economical *possible* nine-trit instruction surface, but the obvious executable nine-word rotation/shift language is physically impossible. Source-authored semantics, not an even larger speculative codebook, remain the missing step.
