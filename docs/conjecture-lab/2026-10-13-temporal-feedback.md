# CL-VLEN-10: four 27-cell quarters as a temporal program with memory

_13 October 2026. DISCOVER/DEVELOP; an invented two-step Boolean recurrence over native physical registration, not an identified CE decoder._

## Conjecture

108 divides naturally into four **27-position quarters**. The physical foreground has distinct early 81 and final 27 symbol alphabets. An optimistic interpretation is that each quarter is a time slice of 27 bits, not another word or plaintext block, and that later slices are generated by an **instruction acting on two earlier slices**. This differs from CL-VLEN-06's elementary cellular automata (one preceding state, spatial neighbourhood) and the Playdead chronology's authentic 32×32 printer/acorn Game of Life overlay (externally supplied seed and rule). Here the *proposed* four-quarter recurrence itself is an invented analogy, not an original Playdead clue.

## Exact model family

For every corresponding 27-cell index `i`, let `Q0_i, Q1_i, Q2_i, Q3_i` be slash-vs-nonslash binary readings. We provisionally map slash=1, dash/dot=0, retaining the physical glyphs distinctly in `data/observations.csv`.

Test:

```
Q2_i = f0(Q0_i, Q1_i)
Q3_i = f1(Q1_i, Q2_i)
```

where each `f` is a two-input Boolean function. There are exactly **16** such functions. We test the **32** fixed-function variants (`f0=f1`) across forward/reversed quarter order and **512** variants permitting a different Boolean operator for the two time steps (16×16, both directions). No fitted spatial rotation, hidden shift, source-specific key, per-cell operator or external target is allowed.

For a given function pair, the 27 locations are independent. Enumerating the four initial values of (`Q0_i`,`Q1_i`) gives **exactly four possible trajectories** for each cell. Retain only those matching whatever physical marks are directly observed at the four matching residues. The model is compatible only if *every one of the 27 locations* admits at least one complete trajectory. Enumerating all 256 ordered Boolean-function pairs and verifying their four-case truth tables gives an independent exhaustive correctness oracle.

## Very cheap structural contradiction for XOR feedback

The natural Fibonacci/LFSR-like rule is XOR, Boolean table **rule 6**:

```
Q2 = Q0 XOR Q1
Q3 = Q1 XOR Q2 = Q0
```

It therefore predicts the first and fourth quarters have **identical slash-vs-nonslash values** at corresponding sites. This is directly contradicted by the physical corpus, with no guessed missing bits:

- **Residue 9 is slash**, but its corresponding fourth-quarter **residue 90 is dot**.
- **Residue 17 is slash**, but its corresponding fourth-quarter **residue 98 is dot**.

A simple bitwise XOR feedback machine cannot be the four-quarter generator in that registration. Different input/output bit-polarity conventions or shifts could change a *different* hypothesis, but they cannot turn this already tested fixed operation into confirmation.

## Speculative follow-ups actually worth distinguishing

1. **Operator is data-dependent:** Let one quarter encode rule indices for the others, rather than all 27 cells sharing the same `f`. Such a program must specify where each rule comes from and preserve unknown marks; otherwise 27 individually fitted rules can reproduce nearly anything.
2. **Unequal temporal distances:** If the cover's 12:12, the acorn's authentic 41, or any new source supplies generation increments, test those exact intervals before generating arbitrary spacings. Our four quarters need not be consecutive snapshots.
3. **Commands operate on a *separate* original printer image:** The CE foreground could select a mask, mutation or readout operation acting on the already-known PC/PS4 printer raster or `534brn` corrupted page. Find the original source-native geometry first.
4. **Change what a 'cell' means:** Nine picture class traces, three 3×9 subregisters or 27 sites by four layers are real arithmetic partitions of 108. This test freezes one natural registration only; other operations require a sourced or explicitly exploratory alternative.
5. **Nested variable-width execution:** A run of 3 or 5 symbols might specify an operand's *interpretation* rather than a temporal Boolean truth table. Short commands can tell the reader whether to look back, skip, change width, reverse or consume an additional run. This is the central broader hypothesis and remains open despite failures of particular languages.
