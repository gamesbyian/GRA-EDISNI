# CL-BANNER-03: three-symbol miniature lettering, outlines and shadows

14 October 2026 | **DISCOVER** mode | **Negative exploratory result**

Follow-up to the [Discord banner-orientation experiment](../2026-10-14-discord-banner-shapes/README.md). Can the three physical sticker symbols serve distinct roles in a word image, such as letter stroke, accent/outline, and background?

## Physical provenance and input variants

The authoritative physical ledger contains **84 sticker records mapping to 66 distinct H108 positions: 36 slash, 22 dash, 8 dot, and 42 unknown**. Earlier conversational wording about seven confirmed dots was outdated. **Sticker 427 confirms residue 103 as a dot, making eight confirmed dots**, all located within the final 27 positions. The screenshot's residue **045 dot** came from an unconfirmed YouTube comment; it is evaluated in a separate sensitivity arm only. No unseen physical symbol has been filled or promoted to evidence.

## The fixed model search

Two banner views are rotated sideways: **4×27 → 27×4** and **6×18 → 18×6**.

Letterforms come from a frozen, explicitly implemented **3×5 A–Z bitmap font**, resized only by nearest-neighbour scaling into these four models:

- 27×4: six 3×4 glyphs, one-cell gaps; five 4×4 glyphs, one-cell gaps.
- 18×6: four 3×5 glyphs, one-cell gaps; three 5×5 glyphs, one-cell gaps.

Every glyph can use four *fixed* three-class pixel grammars: **outline** (orthogonally adjacent to a stroke), **lower-right shadow**, **rightmost stroke pixels as accent**, or **bottommost stroke pixels as accent**. Six assignments of physical slash/dash/dot to core/accent/background are tried. Offset, direction, and natural vs seam-optimized whole-row order are also explored. At every stage unknown cells are ignored, neither 0 nor background.

This is a strong retrospective *selection* search, so **every randomized control repeats the entire search** including letter fitting, role mapping, morphology, direction, offsets and row-order optimization.

Controls: shuffle only *known physical marks within their original row*, preserving each row's exact unknown-cell mask and symbol census. **150 controls for each of four arms.** This preserves the artificial dot concentration generated by late positions.

The best physical 6×18 candidate has just two physically observed dots in matching predicted accent positions. Three-colour styling increases the space for coincidence; it has not yielded an actual decoded message.

Run from the repository root:

    python scripts/conjecture_lab_multisymbol_banner_glyphs.py --widths 4 6 --controls 150 --out out/multisymbol-physical.json
    python scripts/conjecture_lab_multisymbol_banner_glyphs.py --widths 4 6 --controls 150 --include-045 --out out/multisymbol-provisional-045.json
    python -m unittest discover -s tests -p 'test_conjecture_lab_multisymbol_banner_glyphs.py'

The optimizer uses reproducible deterministic greedy starts and 2-opt for whole-row ordering. It does **not** enumerate all 18! or 27! row permutations and makes no such claim. The matched controls calibrate precisely the heuristic **pipeline used**, not a global optimum over every possible row arrangement. Null frequencies are retrospective and conditional on the selected font family; an arbitrary choice of more fonts would increase false-positive opportunities.

**Conclusion:** No positive evidence for a three-colour miniature word image under these four predeclared morphological pixel grammars in either banner orientation. This does **not** rule out images, meaningful word output with some other source-backed font/transform, a dual-layer carrier, cryptographic symbols, or an external observer. Additional stickers are not established as a prerequisite.

**Next decisive clue:** a source-specific font, sticker-native glyph spacing/order, background registration rule, or identifiable receiving artifact would justify another targeted test. The division between first 81 slash/dash positions and final 27 slash/dot positions also motivates testing an instruction/selector tail controlling an earlier body; that is an existing alternative research family, not a conclusion from this font sweep.
