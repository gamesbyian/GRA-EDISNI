**Date:** 16 October 2026. **Mode:** DEVELOP (conditional intended paths), using already preserved historical evidence; **no new sticker acquisition**. This continues [Experiment 324](../experiment-324-expected-player-information.md) rather than replacing its dated information tiers.

## Reconstructing the original player's problem, not ours

The CE's physical object contains one foreground mark, one number and one faint background tile. The packaging context now matters: the sticker sealed the **black-wrapped standalone game item included alongside the CE box**, not the silicone figure itself. See [production history](../archival-manufacturing-evidence.md).

The **background was source-assisted**, per [Experiment 465](../experiment-465-background-url-discovery-provenance.md). A historian should not retell it as a perfectly blind photo-to-URL decode. Its real payoff is still important: collecting different class tiles permitted meaningful spatial assembly and independent route recognition.

## Four conditional player journeys

### A. Single-owner, immediate local payoff

- **Possesses:** only one photographed or physically visible number, mark and partial picture.
- **Plausible first step:** notice that the faint image fragment and unusual three-way mark may require comparison to other copies.
- **Missing instruction:** source-native single-owner lookup, mechanism keyed to the serial, or a different clue telling the player what to do.
- **Falsifier:** an authenticated 2019 artifact that explicitly lets one CE owner derive a nontrivial next step from their own label, or demonstrates a one-label consumer.
- **Current disposition:** unproven; one owner cannot infer the observed global cycle from that label alone.

### B. Collaborative nine-background solution (historically realized, bounded)

- **Possesses:** multiple distinct background classes and an external research community.
- **Action:** identify period-9 image class; assemble physical `IAB/CDE/FGH` background into the printer/route image.
- **Observable feedback:** recognizable art and an authentic reachable/preserved Terminal41 path that was found by archive-index browsing and then associated with the mosaic.
- **Result:** an independently attested solved *background* track.
- **Caution:** the registered URL recognition benefited from the known route dictionary; do not call its precise 21-character spelling an entirely independent output of the drawing.

### C. Collaborative foreground as a separate program/reader

- **Possesses:** pooled class+serial+symbol marks; eventually the H108 and 81/27 structures.
- **Conditional next action:** infer a **native** symbol-to-operation key, read order and target (e.g., already-linked `534brn`, actual printer input, graphical overlay or an in-game operation).
- **Problem:** the first decisive jump from 108 glyph positions to the exact output command remains uncued; 42 distinct symbols remain unseen. A three-way lever analogy exists, but direct known-password readings fail in Experiments 342, 479 and 482.
- **Potential feedback:** reproducible accepted physical/web/game operation or exact source-supported artifact change. No such foreground feedback has been verified.
- **Disposition:** live only as conditional end-to-end sketches. The highly developed ternary machine does not by itself supply a 2019/2020 player's user interface.

### D. No independent continuing foreground payoff

- **Possesses:** same sticker facts and solved background.
- **Action:** foreground glyphs may encode an optional design pattern, a production structure, a later abandoned continuation, or a deliberately open-ended invitation to investigate rather than an actionable receiver.
- **Evidence:** no independently confirmed foreground consumer. Absence of an archive record is not proof no receiver ever existed.
- **Disposition:** keep this genuine rival alive; it incurs fewer invented intermediate consumer steps but must still account for the conspicuous split-alphabet H108 structure.

## Three design-model predictions worth checking without acquiring new stickers

1. **A short user-facing operation:** if the foreground genuinely produces a specific action intended for December-2019 players, some contemporaneous product/game/web artifact must provide discoverable input type or feedback (unless that artifact is lost). Audit the already-preserved original 2019 source corpus, avoiding current web endpoints as substitutes.
2. **Cooperative accessibility:** if success requires a global 108-position reconstruction, identify a documented public/community publication path or redundancy argument allowing the original audience to reconstruct an actionable answer without all printed wrappers surviving. Do not infer universal recoverability from the presently selected machine grammar.
3. **Prior-stage reuse:** if the solved A–I mosaic supplies a key to the foreground, identify **what exact component** of the authentic `534brn` image, page or route acts as that key, and what fixed registration would let a human apply it. Existing reports show attractive nine-digit mappings but missing independent parameters.

## Constraints on every future purported complete solution

A serious complete-solve proposal should fill in this contract **without hindsight laundering**:

| Stage | Minimum required evidence |
|---|---|
| Physical intake | The actual serial, class, glyph evidence available at proposed solve date |
| Collective reconstruction | A method a real participant could discover with that corpus |
| Instruction source | Original artwork/page/record specifying operation, orientation and parameters |
| Processing | Step-by-step human-executable or source-authored computation |
| Receiving surface | A verified game, physical or contemporary web input/reader that fits the output type |
| Feedback | Independent response indicating the operation worked, or an explicit documented absence |
| Temporal feasibility | The reader and source existed by the claimed solve time |

## Outcome and next step

The background path has a real historical completion. Each meaningful foreground-to-reader route in the inspected historical evidence still lacks a **specific coupling instruction**, **accepted input/output record**, or both. The next question is not how clever a 108-symbol transform might be but **which earliest available artifact could have taught the player that transform and accepted its output**.

This is a methodological and source-inventory result, not a new claim that all such artifacts have been searched or cannot exist.
