None is privileged by incumbent G5/G6 machinery. None follows directly from the statistical significance of 108 repetition: all four can make use of a deliberately regular distributed print master.

## A precise identifiability boundary

Let the observable be `O = (serial, background class, foreground mark, ownership provenance)`, where ownership evidence is incomplete and the historic physical production process is not observed.

For **any** conditional complete master `g` consistent with the 84 physical marks, choose four construction histories: (M) encode a target message by an arbitrary author-selected lookup `g`, (S) select `g` as a permitted system output, (I) treat `g` as command/parameter data for a user input system, (N) print `g` for design or abandoned purposes. If these histories are permitted arbitrary hidden author choices, the same 84 `O` values can be generated identically. Therefore **no output-only statistical discriminator exists among these unrestricted models**, even if all 108 positions become observed. This is an existence argument, **not** proof that the four models have equal priors or simplicity.

The meaningful research target is **restricting** those arbitrary hypotheses using authentic independent constraints: print job records, historical game/web inputs, predeclared human interactions, or source-authored rules.

## Three discriminating work packages, all without looking for new stickers

**A. Manufacturing provenance:** inspect already-preserved original packout/production photos, print-layer documents and available source metadata for sticker print-vs-application timing. This discriminates *production DAGs* (preprinted sheet, on-demand, shuffled stock) but not necessarily the four semantic models.

**B. Source-native receiver inventory:** attempt to reproduce a complete known historical 2018–2020 printer/Terminal41/game input→output transaction using already acquired authenticated files. A reader that requires precisely three glyph states, 9/12/27/108 entries, or serial-indexed commands and was present in the contemporary period can discriminate an interaction-first model from unrestricted analogies. Mere integer coincidences do not qualify.

**C. Human-solvability discriminators:** for any M/S/I candidate, give a fully typed single-owner and pooled-owner walkthrough and an independent rule choosing the transform before the answer is inspected. Compare with the no-continuation control and account for archive-discovered route dictionaries. An elegant generated string is insufficient.

## Stopping condition

This capstone reached a rigorous **nonidentifiability result under unrestricted hidden generating choices**. It does **not** prove the puzzle cannot be solved, preclude discovering original ink separation or input source, or close any independently bounded research lane. Keep the four models alive, label the source cues missing for each and prioritize authentic consumer/production constraints over further completion fitting.
