# Experiment 376 — historical repeat/recursion cue hunt after typed G5

_Status: completed bounded provenance audit, 2 Oct 2026._

Experiment 373 changed the target. The question is no longer merely “did anyone ever imagine multiple stages?” It is now much sharper:

> Is there any preserved pre-machine evidence instructing the solver to reuse the same tail selector on the remaining outer Q axis, identify d with Q, or recurse?

The answer remains **no**, but the archive contains stronger near-misses than the earlier G6 provenance summary captured.

## Strongest positive historical material

On 22 May 2026, the sticker discussion explicitly proposed a two-layer 9+3 architecture. The first nine symbols could encode a larger domain and the final three a second number selecting a smaller subset. The immediately preceding analogy used an old phone keypad: one layer selects the key, another selects which letter within that key.

That is unusually close to typed G5. It independently motivates:

- two information layers;
- a larger first-nine domain;
- a smaller last-three index;
- using the smaller value to select within the larger result.

On 20 May the same discussion described the object as potentially “like an onion, layered.”

These are meaningful provenance upgrades for **one selector application**.

## What is still absent

Across the preserved solving-breakout, solving, and TLDR exports, targeted searches for repeat/reuse/again/recursive/outer/inner/nested/hierarchy language did not recover a sticker-specific instruction equivalent to any of:

- reuse the same three-position index again;
- apply the selector to the outer axis after using it on the inner axis;
- identify the inner d coordinate with Q;
- recursively reapply the selection;
- iterate until a fixed point.

The archive therefore still does not independently supply G6.

## The interesting near-miss: Sudoku

On 9 Aug 2026, community discussion independently noticed that Sudoku contains:

- 81 cells;
- 27 houses: 9 rows, 9 columns, 9 boxes;
- total 81 + 27 = 108.

This is the first recovered historical proposal that gives the **27-cell tail an explicit three-family-of-nine interpretation**. It is structurally close enough to deserve a bounded test, but it is not a recursion instruction.

Experiment 377 tests the cheapest exact-cover consequence of that proposal.

## Conclusion

Historical evidence now supports layered selection more strongly than the old G6 write-up suggested, but the support terminates at G5.

The clean epistemic split is:

- **G5:** independently plausible body+index use, now also native-coordinate typed;
- **G6:** no preserved repeat/cross-axis instruction; remains conditional.

The next admissible upgrade to G6 requires a genuinely new source or a separately specified consumer that itself identifies the outer Q axis.
