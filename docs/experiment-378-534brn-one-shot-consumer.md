# Experiment 378 — the nine digits in `534brn9653f9j8mmd` hit the one-shot family

_Status: completed bounded external-consumer test, 2 Oct 2026._

This is the first genuinely specific external hit against the Experiment-374 one-shot object.

## Why this artifact is licensed

The nine-piece CE background puzzle independently resolves to the Terminal41 path:

`dat/534brn9653f9j8mmd`

That string contains exactly nine decimal digits:

`534965398`

This was not invented for the present machine. On 2 Nov 2025, community discussion explicitly noticed that there were nine numbers in the original `534brn` solution and suggested they might help order the nine sticker sections. A direct shuffle using the raw digits did not produce a convincing image, so the idea remained unresolved.

That historical observation licenses treating the nine digits as a bounded sticker-adjacent nine-position object.

## Frozen simple transform

The one-shot G5 endpoint is ternary and 3×3.

The cheapest ordered map from the ordinary decimal digits 1–9 into three ternary states is the equal-third partition:

```
1 2 3 -> 0
4 5 6 -> 1
7 8 9 -> 2
```

Place the nine URL digits row-major:

```
5 3 4
9 6 5
3 9 8
```

The equal-third map gives:

```
1 0 1
2 1 1
0 2 2
```

Now apply only the eight rigid symmetries of the square.

Exactly one orientation hits the preregistered six-state one-shot family:

**rotate 90° counter-clockwise**

```
1 1 2
0 1 2
1 2 0
```

or:

```
112 / 012 / 120
```

That is exactly one of the six Experiment-374 objects.

Its variable middle column is `112`.

## Why this is unusually interesting

This comparison was not generated by scanning arbitrary external strings.

The evidence chain is narrow:

1. the artifact is directly produced by the CE background puzzle;
2. historical solvers independently noticed its **nine digits** as potentially relevant to the nine sticker sections;
3. Experiment 374 independently produced a six-member ternary 3×3 target family;
4. mapping 1–9 into three equal ordered groups is the canonical no-parameter decimal→ternary reduction;
5. only D4 orientation is allowed.

Under those rules the artifact lands exactly on one target.

## Descriptive controls

These are not authorial-intent p-values, but they quantify how specific the match is.

The six one-shot states have 48 distinct patterns after all D4 symmetries.

Against all `3^9 = 19,683` ternary 3×3 grids:

```
48 / 19,683 = 0.00243865
```

about **1 in 410**.

Condition on the observed mapped symbol census, two 0s / four 1s / three 2s. There are 1,260 distinct arrangements with that census. Only the eight D4 orientations of the `112` one-shot state have the same census and hit the target family:

```
8 / 1260 = 0.00634921
```

about **1 in 157.5**.

Again, these are descriptive reference rates, not corrected significance tests.

## Partition sensitivity

A dangerous possibility is that the equal-third split was simply one lucky decimal partition.

So test every monotone way to cut digits 1–9 into three nonempty ordered contiguous classes. There are 28 choices.

Only two cut pairs produce a D4-equivalent one-shot state:

```
(3,6)
(3,7)
```

The first is exactly the canonical equal-third split. The second is observationally identical for this string because digit 7 never occurs.

So, on the actually observed digits, there is effectively **one** successful monotone three-bin classification, and it is the equal-tercile one.

## What this does and does not establish

This materially upgrades the one-shot endpoint as an external-consumer candidate.

It does **not** yet prove that Playdead intended:

- row-major placement of the URL digits;
- the equal-third decimal→ternary map;
- the 90° rotation;
- the resulting state `112/012/120` as a command or final answer.

Those are still interpretive steps.

But the match is much more constrained than the project’s earlier terminal-`100` resemblance searches. The external artifact, its nine-digit cardinality, its sticker provenance, and the target family all existed independently before this comparison.

## Immediate next question

Do not start decoding `112/012/120` semantically.

First ask whether the **90° rotation** and/or the 1–3 / 4–6 / 7–9 grouping are independently indicated by the nine-piece background image, the original sticker-solution orientation, Terminal41 page geometry, or a historical source.

If either parameter is externally fixed, this result becomes dramatically stronger.
