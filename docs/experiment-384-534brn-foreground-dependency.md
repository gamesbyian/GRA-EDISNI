# Experiment 384 — historical dependency direction points from 534brn back into the sticker foreground

_Status: completed provenance audit, 2 Oct 2026._

The current candidate does something potentially dangerous:

> it takes an output from the already-solved nine-piece **background** layer and feeds information from that output into the unresolved **foreground-symbol** layer.

That would be weak if invented only after seeing the one-shot machine.

The historical record independently proposed exactly this direction.

## Puzzle chronology

The CE background image was assembled first. That solved nine-piece layer yielded:

`dat/534brn9653f9j8mmd`

and opened the separate 534brn/Terminal41 artifact.

The foreground dot/dash/slash puzzle remained unresolved.

So chronologically, a solver could possess the 534 output while still needing to solve the foreground.

## Explicit pre-machine proposal

On 2 Nov 2025, while discussing the foreground sticker puzzle, lime8159 wrote that they believed Playdead would have expected solvers to get the `534` puzzle first because the sticker puzzle required much more effort.

They then said the consequence explicitly:

> the 534 solution could have been intended as an aid to this puzzle.

In the same discussion they noticed that `534brn9653f9j8mmd` contains **nine numbers** and wondered whether those could relate to the nine sticker sections.

This predates the present machine by nearly a year.

## Why this matters

Experiments 378–383 require the information-flow direction:

```
solved background
      ↓
534brn path
      ↓
derived nine-state / ternary registration information
      ↓
foreground one-shot object
```

Experiment 384 shows that the first three arrows are not merely a modern reconstruction. The community independently proposed the same cross-stage architecture before the current model existed.

This also matches a demonstrated broader INSIDE ARG design grammar: prior-stage outputs can become parameters or selectors for later artifacts when the handoff is independently cued.

## What this does not prove

The historical proposal does not tell us **which** part of 534brn is the aid.

It does not specify:

- DTMF keypad row;
- native serial registration;
- 90° CCW;
- `112/012/120`;
- any semantic meaning for that state.

So this is a provenance upgrade for the dependency direction, not a decoder.
