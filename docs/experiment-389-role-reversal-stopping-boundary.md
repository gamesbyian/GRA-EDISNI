_Status: completed negative provenance audit, 2 Oct 2026._

After Experiments 378–388, the active `534brn` candidate has become highly constrained.

The remaining question is no longer “what transform should we try?”

It is:

> Is there any independent source that fixes the exact role assignment and q reversal selected by Experiment 386?

A targeted replay of the preserved archive and current mechanics corpus searched for sticker-specific evidence equivalent to:

- background physical column becomes outer `Q`;

```

```

The project now has enough structure that continued transform invention would actively make the result worse.

- an independently sticker-derived nine-digit artifact;

What it lacks is **one authorial or external cue fixing the exact remaining registration**.

That is a clean stopping boundary.
