# Experiment 394 — Braille projection over weighted/coherent completion ensembles

_Status: completed bounded exploratory test, 4 Oct 2026._

The weighted-completion sandbox lets us try operations that could not be tested cleanly while 43 H108 cells were blank.

Braille is a legitimate first test because it is a **demonstrated INSIDE ARG operation family** in the Xbox printer puzzle.

## Preregistered carrier

Do not pour the 108 symbols into arbitrary rectangles.

Use the native complete class-word carrier:

- 9 rows = A–I background/serial classes;
- 12 columns = the twelve positions of each class word.

A 9×12 grid partitions exactly into eighteen standard 3-row × 2-column six-dot Braille cells.

Test only two independently natural class-row orders:

1. serial/community A–I;
2. solved physical background order `IAB/CDE/FGH`, flattened as `IABCDEFGH`.

For the binary layer, test only:

- slash = raised;
- its complement.

That is the entire family.

## Why ensembles matter

A single modal guessed master could easily spell accidental fragments.

So the test is run over:

- all **648 U2** coherent broad completions;
- all **20 U4** one-shot completions.

A Braille cell counts as stable only if every completion in the relevant ensemble gives the same six-dot pattern.

## Result

The best U2 projection fixes only 6 of 18 Braille cells.

The best U4 projection fixes 8 of 18.

Some stable cells happen to be ordinary Braille letters. For example, A–I/slash-raised gives stable letters including `b,w,r,o` at U2 and adds `l,a` at U4.

But across **all eight ensemble/configuration combinations**, the longest consecutive run of stable alphabetic Braille is only:

**2 cells.**

No stable message emerges.

The scattered letter-like cells are exactly the sort of thing a single guessed completion could make seductive. Ensemble testing punctures that balloon before it floats away with the afternoon.

## Conclusion

The cheapest sticker-Braille interpretation is negative.

That is useful. It demonstrates the value of using the guesses as counterfactual models rather than as a single filled-in answer sheet.

Close this Braille projection unless a new artifact independently supplies a different packing, polarity, or registration. Do not widen into arbitrary row permutations to hunt words.

## What to try next

The sandbox remains valuable for operations with stronger sticker-native cues:

- historically attested lever semantics, once an independent subset/order exists;
- boundary/check-bit style registration if a sticker-native margin channel is found;
- prior-stage selectors such as `534brn`;
- coordinate-role operations like DTMF/Polybius where a specific external artifact supplies the input.

The key question for every new approach is now:

> does the result survive coherent alternative completions, or does it exist only because we guessed the missing stickers one convenient way?
