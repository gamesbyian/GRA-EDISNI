# Experiment 395 — weighted completion exploration program

_Status: active program definition, 4 Oct 2026._

Experiment 393 established that the existing prediction matrix is useful as an ensemble of coherent counterfactual completions, not as a single modal completed code.

This experiment turns that methodological result into an operating program.

The canonical panels are U2, U3, U4, U5, the two externally selected `534brn` masters, and frozen rivals when relevant. New operations must be evaluated by invariant outputs, survivor counts, cross-layer discrimination, and sensitivity to uncertain residues rather than by semantic attractiveness of one guessed completion.

The active workstreams are:

1. externally specified consumers/selectors;
2. bounded registration/check-bit structure;
3. lever semantics only when subset/order is independently supplied;
4. coordinate/selector operations already licensed by historical evidence;
5. residue-sensitivity maps that turn computation back into prospective physical tests.

`docs/weighted-completion-exploration-plan.md`

The first two executed probes are Experiments 396 and 397.
