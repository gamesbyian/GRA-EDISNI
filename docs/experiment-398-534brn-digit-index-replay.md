## Lever projection

The Collector's Edition sleeve / secret-ending-lever cue independently supplies:

```
/ -> U
- -> R
. -> L
```

Therefore the stable sequence would become:

```
RRURRURUR
```

However, there is an important structural limitation.

The digits are all 1–9, so this index rule samples only the nine-cell primary body of each class word. It can **never** select the final three tail positions, which are the only positions capable of carrying dots under the current foreground structure.

So this index operation is intrinsically binary:

```
dash / slash
right / up
```

It cannot produce a left command.

- the nine values and nine sections are independently paired;

But stability alone is not semantic evidence.

The result should therefore be preserved as:
