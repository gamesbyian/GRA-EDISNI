# Experiment 406 — weighted historical-cipher pruning checkpoint

_Status: completed synthesis checkpoint, 4 Oct 2026._

Experiments 393–405 were designed to answer a practical question:

> can the missing-sticker prediction ensembles let us test old community decoding ideas that were previously impossible to evaluate cleanly?

Yes.

The result is not a solved plaintext, but it is a substantial reduction of the historical hypothesis space.

## Surviving / useful surfaces

### 534brn digit-as-index signature

Experiment 398 replays the independently historical proposal that the nine digits in `534brn9653f9j8mmd` index the nine sticker sections.

The direct one-based native-class replay becomes completely stable by the typed one-shot layer:

```
--/--/-/-
```

This is a real ensemble-stable derived feature.

Its cheapest semantic interpretation through the sleeve/lever mapping gives:

```
RRURRURUR
```

but Experiment 401 shows that exact nine-command word occurs at least 106 times in surviving 2023 De Bruijn lever sections that were physically tested in-game with no new result.

So:

- the indexed signature survives;
- direct bunker-lever semantics do not.

### Historical 9+3 numeric surface

Experiment 399 preserves the May-2026 proposal that the first nine cells encode a larger binary value and the tail a smaller selector.

For the two externally selected masters, the A-I body values are fully fixed:

```
302, 382, 58, 151, 311, 407, 369, 129, 357
```

The tail is one-hot and therefore carries a three-state selector rather than a generic 0–7 integer.

This representation remains open because no independently specified page/table/record consumer is known.

## Closed cheap families

### Contiguous 9+3 subset selection

Experiment 400 tests the literal alternative in which the tail chooses one contiguous three-bit Q chunk from the first-nine body.

Both one-dash and one-slash ternary readouts have:

```
0 survivors
```

across U2/U4/U5/E2.

The historical body+selector intuition therefore aligns much better with typed strided d-selection than with contiguous Q-chunk selection.

### Standard 3×36 Trifid

Experiment 402 faithfully replays the Dec-2022 3×36 Trifid proposal against all U2 completions.

Across:

```
36 cheap standard decoder configurations
×
648 U2 completions
```

the historical partial plaintext has zero survivors.

The first two claimed letters C/U already force a unique cheap decoder, which then makes the third claimed letter impossible.

Standard unkeyed direct-cube Trifid is closed unless a historical key/period/fractionation rule is independently recovered.

### Direct serial Fractionated Morse

Experiment 403 exhausts all six sticker-symbol assignments to the standard Fractionated-Morse symbols.

Every mapping fails for every U2 completion because the serial stream contains invariant uniform triples of all three sticker symbols. Whichever symbol becomes the separator `x`, a fixed forbidden `xxx` appears.

This lane is structurally closed absent an externally supplied rearrangement.

### Direct slash-separated Morse

Experiment 404 tests ordinary serial Morse with slash as separator.

All U2 completions contain the invariant block:

```
/------/
```

which forces an invalid six-mark Morse token under either dot/dash polarity.

Closed.

### Native class-word Morse

Experiment 405 gives Morse its strongest cheap rearrangement: the independently native 9×12 class-word carrier.

Class H is invariantly:

```
-/------/../
```

again forcing a six-mark token.

Closed.

## What the weighted sandbox has taught us

The prediction ensembles are most useful not for hallucinating a completed answer, but for exposing **structural impossibilities**.

Several historically plausible ideas can now be rejected without waiting for the missing 43 residues because the contradiction is invariant across every broad U2 completion.

This is a stronger use of the weighted lists than choosing a preferred completion and asking whether it spells something.

## New stopping boundary

The cheap historically attested classical-cipher lane is now sufficiently pruned.

Do not proceed to:

- keyed Trifid brute force;
- arbitrary Fractionated-Morse permutations;
- arbitrary Morse rearrangements;
- A1Z26/base-N plaintext fishing;
- arbitrary books for the 9+3 numeric values.

Reopen one of those only when an external artifact supplies the missing key, traversal, period, corpus, or consumer.

## Best live consequences

At this checkpoint the strongest still-live computational surfaces are:

1. the externally anchored `534brn` coordinate/isomorphism candidate selecting two one-shot masters;
2. the robust indexed signature `--/--/-/-`, but without its lever consumer;
3. the fixed E2 9-bit numeric vector, awaiting an external numeric consumer;
4. physical acquisition targets at residues 82, 84, 102, 103 and 45.

The next computational work should therefore return to **external-consumer discovery and prospective physical discrimination**, not broader cipher enumeration.
