# Experiment 409 — reversible-cover clue audit

_Status: completed provenance/source-structure audit, 4 Oct 2026._

The external-consumer program has spent considerable effort on abstract consumers while one unusually strong physical clue source was still sitting in the archive: the PS4 reversible cover.

This experiment re-establishes exactly what is independently known before trying to use it.

## It is definitely meant to contain a clue

The cover is not merely decorative artwork that solvers decided to stare at.

iam8bit explicitly advertised the reversible slip cover as containing a hidden clue, and the community repository has long kept it as an unresolved active mystery.

That gives it substantially more evidentiary weight than generic scene artwork.

- `INSIDE_B-80fbff1237c37913.JPG`

The April-2020 Discord archive independently records that the community had recently obtained high-quality scans specifically to improve cover analysis.

So this lane is not blocked on another low-resolution screenshot hunt.

## What the cover independently contains

Historical solving notes and preserved comparison assets identify several screen/scene elements:

- the clock reads **12:12**;
- one monitor contains imagery from the PC/PS4 acorn puzzle;
- that acorn representation is visibly incomplete / only the upper portion;
- another monitor contains a planet-like display associated with the Xbox-printer visual family;
- other monitors were compared against graph and login-screen assets;
- a running-man-like figure exists in the physical scene outside the monitor imagery.

These identifications existed well before the present sticker-machine work.

## The historically proposed operation is important

In April 2020, community discussion explicitly suggested that the cover might be a **guide to the puzzle family** rather than a standalone ciphertext.

The reasoning was that its screens appear to reference earlier ARG products, while at least one reference is only partial.

Later discussion explicitly wondered whether the clue involved:

- layers;
- completing one representation with another;
- digitally reversing the reversible cover;
- comparing the screen representation with elements present elsewhere in the physical scene.

This is not proof of any one operation.

But it does provide independent provenance for a family we previously had to treat cautiously:

> cross-artifact composition / partial-image completion / layer registration.

## What this licenses

The cover now licenses bounded tests in which:

1. an independently identified cover element points to a known prior ARG artifact;
2. that artifact supplies its own coordinate system, mask, partial image, or operation;
3. registration parameters are fixed by visible cover geometry or exact source-image correspondence before sticker output is examined.

This is a legitimate consumer/key-search lane.

## What it does not license

The following remain forbidden:

- sliding a 3×3 sticker grid around the cover until something looks meaningful;
- arbitrary rotations, crops, rescalings or transparency values;
- treating every monitor/object as one of nine sticker states merely because nine is useful;
- interpreting 12:12 as a sticker key without another independent bridge;
- generic image-difference or steganography fishing.

The cover is a clue source, not a blank cheque.

## Relation to the weighted-completion sandbox

This is potentially valuable because it can supply exactly the thing the sandbox now requires: **a parameter from outside the sticker corpus**.

If a cover monitor or scene element yields a definite:

- subset;
- orientation;
- mask;
- layer order;
- traversal;
- prior-puzzle output;

then the corresponding operation can be replayed over U2/U4/U5/E2 rather than tested on one guessed completion.

## Current conclusion

The reversible cover does not yet consume the stable nine-symbol signature or the frozen 9+3 numeric interface.

But it materially upgrades one operation class:

> use exact prior-puzzle visual references as registration anchors for a layered or partial consumer.

The next cover work should therefore be forensic and source-matched, not semantic: identify each monitor image against its canonical source asset and determine whether the **differences/omissions themselves** define a reproducible operation.
