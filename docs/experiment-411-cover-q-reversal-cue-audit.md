# Experiment 411 — can the reversible cover supply the missing q-reversal cue?

_Status: completed cue-specificity audit, 4 Oct 2026._

The active `534brn` coordinate match remains one exact registration cue short.

Its robust surviving parameter is:

```
q' = 2q + 2 mod 3
```

which reverses the outer-layer order:

```
0,1,2 -> 2,1,0
```

The reversible cover is therefore worth testing as a possible independent reversal cue.

## External evidence

Three facts exist independently of the present machine:

1. the cover is physically **reversible**;
2. the clock on the clue-bearing artwork reads **12:12**;
3. in March 2022 a community solver explicitly proposed digitally reversing the reversible side because of that clock.

So “reversal” is not an operation invented after seeing the `534brn` match.

## Why it still does not fix q

The problem is specificity.

A reversible printed cover naturally permits several inequivalent operations:

- front/back swap;
- horizontal mirror;
- vertical mirror;
- 180° rotation;
- reading the wrapped panel in the opposite direction;
- digital mirroring of one side.

Nothing on the cover labels any of these as the machine's outer `Q` coordinate.

Nothing independently says:

```
Q0 <-> Q2
Q1 fixed
```

And the 2022 “reverse it digitally” statement is a solver proposal, not an authorial instruction recovered from the artifact.

Therefore the cover supplies:

> reversal / re-registration as an independently natural operation family

but not:

> the exact affine q gauge `q'=2q+2`.

## Relation to Experiment 389

Experiment 389's stopping boundary remains intact.

The cover makes the surviving q reversal feel less exotic, but it does not convert it from a fitted parameter into an independently fixed one.

That distinction matters.

## Reopening trigger

The cover could close the gap only if further forensic work finds something like:

- an arrow or explicit reading direction;
- two labeled endpoints corresponding to outer Q layers;
- a repeated source-image transform that specifically swaps first/last while preserving middle;
- a three-stage sequence with a visually fixed order.

Absent that, retain the `534brn` match as strong-but-one-cue-short.
