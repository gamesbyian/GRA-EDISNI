# Experiment 412 — no repeated source→cover transform yet

_Status: completed bounded cross-pair audit, 4 Oct 2026._

Experiment 410 proposed the right next question for the reversible cover:

> do multiple independently identified monitor/source pairs use the same transformation?

A repeated operation would be much stronger evidence than four thematic references.

## Pair-by-pair status

### Login

The cover monitor is directly compared against the recovered login-screen asset family.

No independently documented crop, reversal, half-image extraction, or other nontrivial transformation has been recovered.

### Graph

The cover monitor is likewise compared against graph-like source/game imagery.

Again, no repeated nontrivial transform is independently established.

### Acorn

This is the strongest transformed pair.

Historical discussion repeatedly notes that the monitor shows only the **top / partial** acorn-style image rather than the full solved form.

This genuinely supports partial-image behavior.

### Planet

The monitor is clearly treated as part of the planet-image family, but historical discussion explicitly says it is not simply the final solved “NEW PLANET DISCOVERED” image.

That is intriguing, but the exact source→cover operation remains unidentified.

## Cross-pair result

There is currently no common transform such as:

- crop top half;
- mirror;
- reverse;
- rotate 90°;
- complement;
- isolate one color channel;

that is independently demonstrated on multiple monitor/source pairs.

The acorn partiality is therefore a **single positive example**, not a repeated codebook.

## Consequence

Experiment 409's operation-family upgrade should be kept, but not overstated.

The cover is good evidence for:

> references between puzzle/image layers can be deliberate.

It is not yet good evidence for:

> apply operation X to the sticker foreground.

The next valid advance requires identifying the planet relation or another monitor relation precisely enough that the same transform appears twice.

## Stopping rule

Do not tune image transforms to make two pairs agree.

A common transform must emerge from source identification and visible cover geometry before sticker outputs are consulted.
