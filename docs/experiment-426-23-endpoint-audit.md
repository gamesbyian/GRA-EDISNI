# Experiment 426 — bounded 23-sensitive production-total audit

## Question

Does the newly salient number **23** make any production-total candidate already considered by the project unusually compatible with the independently established sticker carrier?

The candidate set is frozen to totals discussed before Experiment 424:

`598, 600, 603, 612, 621, 630, 639, 648`.

The audit admits only existing carrier numbers `9, 27, 81, 108` plus the newly motivated `23`. It does not search arbitrary sums, products, nearby totals, digit manipulations, or aesthetic formulas.

### 598

```
598 = 23 × 26
```

This is a clean 23 multiple, but it has no alignment with the already-established 9/27/81/108 carrier geometry.

Also, observed serial 597 does **not** establish a total of 598. That inference requires a zero-based, contiguous physical run, which manufacturing evidence has not established.

### 621

```
621 = 23 × 27
    = 27 × 23
    = 69 × 9

621 = 5×108 + 81
```

This is unique within the frozen candidate set.

It is one of only two candidates divisible by 23, the only one divisible by both 23 and 27, and it lands exactly at residue 81 of H108.

Under a hypothetical 001..621 contiguous run, the endpoint would therefore occur after five complete H108 cycles plus the complete 81-cell primary region of the sixth cycle, immediately before that cycle's 27-cell tail.

Equivalently, the whole run can be partitioned as either 23 blocks of 27 stickers or 27 blocks of 23 stickers.

Those relationships use numbers independently present in the sticker system rather than newly invented factors.

### 648

```
648 = 6 × 108
    = 24 × 27
    = 8 × 81
    = 72 × 9
```

648 remains the strongest endpoint under the **pre-23** carrier geometry. It closes six complete H108 cycles exactly and is simultaneously aligned to 9, 27, and 81.

It is not divisible by 23.

## Interpretation

The 23 observation does not make every endpoint look interesting. It separates the candidates sharply:

- **598** receives one new property: divisibility by 23.
- **621** receives a conjunction: divisibility by 23 and 27 plus exact termination at the 81/27 H108 boundary.
- **648** remains the cleanest conventional carrier endpoint but gains nothing from 23.

So if 23 later receives independent confirmation as an authorial quantity, **621 becomes a particularly strong structural endpoint candidate**.

At present this is still structural compatibility, not production evidence. The archival/manufacturing lane remains explicit that serial 597 proves only that a high serial existed, not how many labels or Collector's Editions were produced.

## Disposition

Preserve 621 as the leading **23-sensitive** endpoint hypothesis and 648 as the leading **legacy-carrier** endpoint hypothesis.

Do not collapse them into one ranking until an independent source establishes either:

- 23 as an intended sticker quantity/operator;
- the actual print-run endpoint;
- a label-sheet/imposition geometry;
- or whether the serial space was contiguous and one-based/zero-based.
