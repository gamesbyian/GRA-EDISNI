# Experiment 426 — bounded 23-aware endpoint audit

## Question

Does the newly noticed number 23 make any historically discussed sticker-production total structurally special, particularly 598 or 621?

This audit deliberately avoids searching arbitrary totals for attractive arithmetic. It freezes the endpoint candidates already discussed in the project:

`598, 600, 603, 612, 621, 630, 639, 648`.

It compares them only with quantities already motivated by the sticker carrier or by Experiment 424:

- 9: background/class period;
- 23: IBM 029 period-code row-label sum, newly salient but not yet an established carrier dimension;
- 27: native tail / q-block scale;
- 81: native primary region;
- 108: established foreground period.

## Results

| total | exact structural divisors | mod 108 | notable identity |
|---:|---|---:|---|
| 598 | 23 | 58 | `23×26` |
| 600 | none | 60 | round-number manufacturing guess only |
| 603 | 9 | 63 | |
| 612 | 9 | 72 | |
| **621** | **9, 23, 27** | **81** | **`23×27 = 5×108+81`** |
| 630 | 9 | 90 | |
| 639 | 9 | 99 | |
| **648** | **9, 27, 81, 108** | **0** | **`6×108 = 8×81 = 24×27`** |

Two candidates clearly stand apart.

### 621

621 has a compact intersection of the newly salient and previously established structures:

```
621 = 23 × 27
621 = 27 × 23
621 = 5 × 108 + 81
621 mod 108 = 81
```

So it can be viewed as either 23 groups of 27 or 27 groups of 23, and its endpoint lands exactly after the 81-cell primary region of an H108 cycle, immediately before the 27-cell tail.

If 23 is independently promoted to an authorial number, 621 becomes a particularly economical production-total hypothesis because no additional operation is needed to connect 23, 27, 81 and 108.

### 648

648 remains the strongest carrier-only endpoint:

```
648 = 6 × 108
648 = 24 × 27
648 = 8 × 81
```

It closes six complete H108 cycles exactly. Its old appearance in the historical interval scanner is not manufacturing evidence, but the arithmetic endpoint itself is structurally natural.

### 598

598 is exactly:

```
598 = 23 × 26
```

This is interesting if the total count really were 598, but it has no additional alignment with 9, 27, 81 or 108. It is therefore weaker than 621 as a 23-aware structural endpoint.

There is also an indexing trap: highest observed serial 597 does **not** imply 598 stickers unless the physical run is known to include serial 000 and to be contiguous. The repository's H108 “residue 0” convention is modular bookkeeping, not evidence that a physical sticker 000 existed.

## Comparison to old “sum to 23” observations

A bounded scan of prior experiment summaries finds several pairs of small quantities that sum to 23, especially:

- 20 + 3;
- 9 + 14;
- 5 + 18;
- 19 + 4;
- 13 + 10 in an older state accounting.

These are useful as a null warning. The project contains many ternary, 9-cell, state-count and completion-count quantities, so post-hoc addition can manufacture 23 fairly easily.

The endpoint result is stronger specifically because **621 itself is an exact product of 23 and the independently established native scale 27**, and simultaneously lands on the independently established 81/27 boundary.

There is no nontrivial positive-integer multiplication equal to 23 because 23 is prime: only 1×23. The meaningful multiplication question is therefore whether established totals are **multiples of 23**.

## Evidentiary boundary

Sticker 597 proves that serial 597 exists. It does not establish:

- how many Collector's Editions were manufactured;
- whether serials began at 000 or 001;
- whether every serial in the interval existed;
- whether iam8bit retained an end-of-run unit;
- whether the total was 598, 600, 621, 648, or another number.

Historical “about 600” discussion is explicitly speculative.

## Disposition

**621 is now the most interesting 23-aware endpoint, while 648 remains the most natural endpoint from H108 alone.**

Do not choose between them numerologically. A genuine manufacturing count, a physical sticker above 597, an independently sourced 23 cue, or an authorial grouping instruction would provide the discriminator.
