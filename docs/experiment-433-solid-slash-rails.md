# Experiment 433 — solid slash rails in the native 4×27 carrier

## Observation

Rendering H108 directly as four consecutive 27-cell quarters reveals three columns that are slash in every quarter across all 10 live canonical completions:

```
columns 5, 13, 15
```

Thus in the hypothetical 23×27 / 621 rectangle, those positions extend into three solid slash rails running through all 23 rows.

Column 15 corresponds to:

```

```

All four are physically observed slash.

```

```

Residues 13 and 40 are physically observed slash; 67 and 94 are currently completion-invariant slash in the live structural family.

So two of the three rails are already direct physical-corpus facts, not model-filled visual artifacts.

## Hollerith relation

Under the literal IBM row-label sum, slash has value 1. A 23-row solid slash rail therefore has column sum:

```
23 × 1 = 23
```

Columns 5, 13 and 15 each have Hollerith-weighted sum exactly 23 in the hypothetical 23×27 rectangle.

This is an arithmetic consequence of the rail length and slash weight, not independent evidence for 23.

## Interpretation

This is a genuine visible pattern in the native 4×27 carrier and becomes especially conspicuous when extended to 23 rows.

However, it does **not** depend on 621: the four-cell slash columns already exist inside one H108 master. The 621 hypothesis merely repeats them vertically.

Preserve the rails as a useful visual landmark and prospective check. Do not treat them as evidence for the endpoint unless an external artifact independently indicates vertical strips, 27-column imposition, or these column positions.
