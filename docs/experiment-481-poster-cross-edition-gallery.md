# Experiment 481: publisher nine-sketch poster and cross-edition marketing control

*8 October 2026. Source-native artwork inventory; no sticker overlay generated.*

## Stronger source evidence than a generic nine-slot coincidence

[Official iam8bit Collector's Edition product](https://www.iam8bit.com/products/inside-collector-s-edition)
displays a foldout poster on which **nine different concept sketches
appear approximately in three rows of three**. The poster is a
*real, authored, contemporary material* rather than a rectangular
grid placed on an unrelated painting for an experiment. A red
INSIDE title, visible folds, large white margins and faint bottom
printer-credit text are evident in the lifestyle photo.

Original CE gallery image examined:

`https://www.iam8bit.com/cdn/shop/products/InsideCE_Lifestyle_00014_cf6a9295-f926-4f34-880f-2ddd6d75ce3d.jpg?v=1588895007&width=3648`

Nine sketches are a reasonable visual count, **not** independently
established stickers A–I. The photo is oblique, and neither the
original full-resolution front/back print master nor a reliable
registration grid has been acquired. No printed A–I letters or
slash/dash/dot legend can be verified from the supplied page.

## New cross-edition control: the publisher reused the scene itself

The **standalone**
[iam8bit INSIDE PS4 physical game product](https://www.iam8bit.com/products/inside-ps4-physical-game)
also includes a **foldout poster with exclusive original art**.
Crucially, its **own official gallery** displays the same distinct
lifestyle scene: the PS4 case/disc on a metal surface next to
the white poster with the nine sketches, the same sketches
in the same positions, and the same red INSIDE title.
The file URL here is:

`https://www.iam8bit.com/cdn/shop/products/InsideCE_Lifestyle_00014.jpg?v=1588895388&width=5472`

The CE listing's image basename starts
`InsideCE_Lifestyle_00014_cf6a...`, and the standalone
listing uses `InsideCE_Lifestyle_00014.jpg`. The same visual
scene is clear from the two official page galleries; *original
image bytes, crop transforms and hashes have not been compared*.
This supports **promotional image reuse across the two product
listings**. It does not prove the exact printed sheet shipped in
each box was identical.

The historical [1 December 2019 physical-edition announcement](https://www.gamereactor.eu/playdead-releasing-physical-edition-of-inside-with-iam8bit/)
specifies that the standalone version was limited to **2,000
copies**, was expected to ship after the Collector's Edition
fulfillment, and itself included a foldout poster. This chronology
provides a genuinely **non-CE-sticker audience** to consider.
The original standalone product listing even hints it was
“perhaps more than it seems,” but that sentence is **not**
an instruction identifying the nine sketches as a sticker codebook.

It therefore remains possible that poster art was a more general
INSIDE retail clue. It is unsound to promote its visual 3×3 into a
**CE-exclusive receiver** merely because the sticker backgrounds
have nine classes.

Other CE gallery photos explicitly show **numerous separate
concept art cards** (e.g. `InsideCE_Lifestyle_00018.jpg`

control against imagining a mandatory nine-card A–I codebook
from the number of sticker-background pieces alone.

## Exact actionable physical comparison

1. Obtain an authenticated standalone PS4 pack-in poster and CE
   poster **fully unfolded, both sides**, as original print art or
   high-resolution orthogonal scans with edition provenance.
2. Compare the two *as shipped*, after correcting scanner rotation
   without choosing a transformation against stickers: artwork,
   crop, fold-grid registration, hidden margins, print credits and
   reverse-side glyphs.
3. If either includes an independently authored symbol legend,
   A–I class correspondence or multi-artifact overlay instruction,
   **freeze that geometry before using any guessed missing
   foreground marks**.
4. Otherwise retain the nine-sketch arrangement as a sourced
   spatial prior and a **non-unique visual analogy**, not a solved
   receiving artifact.

## Result

**Source-backed advance:** The publisher not only supplied an
approximately nine-sketch grid, but reused the exact promotional
scene on the separately sold standalone edition's gallery.
That meaningfully changes the exclusivity question.

**Remaining essential bridge:** an original sticker-to-poster
reader specifying coordinate registration and operations;
the physical sheet identity and reverse side are still unknown.
