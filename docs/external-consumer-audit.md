# Evidence-Gated External Consumer Audit

## Purpose

The closed-corpus sticker mechanism is substantially solved. The terminal `100` is mechanically established, but no downstream plaintext, URL, instruction, image, lore phrase, or external endpoint has been demonstrated.

This lane asks a narrower question:

> Does any independently motivated INSIDE / Collector's Edition / historical ARG artifact contain a structure that can plausibly consume or mirror the solved machine?

Do **not** assume that such a consumer exists. A clean negative result leaves `100` as the project endpoint.

## Entry rule

An external semantic branch may be opened only when the external artifact supplies the cue first.

Acceptable entry cues include independently visible or documented:

- three-position exceptional-member coding;
- 3 / 9 / 27 / 108 organization;
- a native 3×3 or 3×3×3 addressable structure;
- repeated literal address substitution or routing;
- the exact route family `120 / 012 / 102`;
- the `210` selector baseline;
- a `14 -> 3 -> 1` collapse;
- a terminal `100` in a context where ternary positional state is already independently justified;
- the complete-master census `54 / 36 / 18 = 3:2:1`;
- another exact machine fingerprint that was derived before looking at the candidate artifact.

Weak thematic resemblance is not enough.

## Priority targets

### 1. Reversible PS4 cover / sleeve

Treat the unresolved reversible cover as the highest-value external target because it is a bounded physical artifact already associated with the ARG.

Acquire the best available front/back/inside scans and record their provenance. Audit the artwork before overlaying the solved machine.

First-pass questions:

- Are there explicit 3-, 9-, 27-, or 108-part groupings?
- Is there a repeated 3×3 registration grid or another naturally addressable lattice?
- Are exceptional elements distributed one-per-three in any independently visible family?
- Does the artwork supply its own alignment anchors for a 3×3 or 3×3×3 registration?
- Do any independently identified marks map to the machine fingerprints above without choosing an arbitrary offset, scale, rotation, crop, or polarity?

Do not grid-search arbitrary overlays for attractive fragments. A registration must be justified by the physical artwork itself.

### 2. Collector's Edition printed and structured materials

Audit printed packaging, art cards/inserts, labels, sleeve material, and other structured CE components before treating the sculpture itself as a code surface.

Prioritize objects that naturally contain:

- repeated cells;
- numbered or aligned positions;
- three-state or one-exception-of-three structure;
- nine-part layouts;
- addressable nested geometry.

The sculpture can be inspected for the same fingerprints, but visual resemblance to `1-0-0` alone is not evidence.

### 3. Historical ARG and platform-specific artifacts

Revisit archived printer outputs, site assets, scripts, route names, downloadable files, and platform-specific puzzle material as **external structure**, not as a library of old decoder recipes.

Search for exact homologues of the solved machine:

- ternary positional rails;
- 9/27/108 addressing;
- `120/012/102`, `210`, or `100` inside an independently ternary context;
- literal recursive coordinate replacement;
- rank-collapse behavior.

Known decoder families already audited in Experiment 240 remain closed unless a newly inspected artifact independently points back to one.

### 4. Terminal 41 archives

If archived Terminal 41 source, scripts, route inventories, assets, or snapshots are recoverable, inspect them for explicit structural affordances first.

High-value evidence would be an independently present ternary/state/address interface that matches the solved machine.

Do not spray:

- `100`;
- decimal/hex conversions of `100`;
- all 14 hidden states;
- `XYZG` bit strings;
- thermometer words;

into historical paths, APIs, or parameters without an externally justified input grammar.

### 5. Later Playdead / Project 3 material

Treat later-game material as a low-priority comparison corpus, not as an assumed destination.

Promote a candidate only if it independently exposes one of the machine fingerprints. Generic sci-fi, planet, probe, printer, laboratory, or three-state imagery is insufficient.

## Explicitly quarantined hypotheses

Retain these only as conditional hypotheses that require an external cue before testing:

- the four-bit observer word `XYZG` is a semantic payload;
- `100 / 110 / 111` are audio frequencies, pitch ratios, or spectrogram parameters;
- `100` is a URL/API/path parameter;
- the terminal should be converted to decimal, hex, ASCII, Morse, Braille, or another generic code;
- a 3×3 mask should be freely overlaid on arbitrary artwork;
- the CE sculpture encodes `1-0-0` merely because three distinguishable regions can be found.

The observer bus is currently best explained as a redundant state observer. The thermometer staircase is a recoding of one ternary control state. Neither supplies free semantic bandwidth.

## Falsification discipline

For every candidate external artifact:

1. record the artifact and provenance before interpretation;
2. identify the external cue that licenses comparison;
3. preregister the machine fingerprint being tested;
4. define registration/orientation/polarity choices before reading the result;
5. count the available degrees of freedom;
6. test negative controls or alternate registrations where practical;
7. record both hits and null results.

A candidate becomes interesting only when the match is substantially more specific than the available fitting freedom.

## Stopping rule

If the bounded targets above contain no independently registered machine homologue or consumer, keep the semantic branch closed.

The default conclusion remains:

> `100` may be the intended mechanical endpoint.

External-consumer work must never be allowed to weaken that conclusion merely because a continuation would be narratively satisfying.
