# Original-game ordinary-detail clue hunt (9 October 2026)

**Mode:** DISCOVER for candidate discovery; DEVELOP only for explicitly conditional sticker-consumer sketches; **no VALIDATE decoder claim**. This is a source/provenance and acquisition campaign, not a new physical sticker observation or a completed cipher. Owner outreach is not part of this plan.

## Objective and decision rule

Seek a real authored INSIDE (preferably 2016) detail that **independently determines** sticker registration, orientation, ordering, selected coordinate, glyph semantics, operation, or receiving surface. Numbers shared with the CE 108-cycle (9, 12, 4, 3) are *search cues*, not evidence of a relationship.

Useful original detail should: (i) exist in original game / CE-era artifact; (ii) have source-native discrete geometry; (iii) constrain an ambiguity already present in CE observations; (iv) specify an operation or input affordance; (v) require few source-unsupplied orientation/role choices; (vi) yield an external check or frozen prediction. Always test mundane gameplay, reused prop and dead-content explanations first.

**Physical CE denominator (latest audited):** 84 owner observations, 66 unique H108 residues, 42 missing residues. H108, A–I period 9, first 81 slash/dash versus last 27 slash/dot are observations. POS3, four-cube readout and terminal 100 are *model-conditional*; do not promote them into source facts.
