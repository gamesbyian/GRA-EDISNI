# Experiment 270: Q4 gauge physical simplicity

Experiment 260 showed that the recursively closed Q4 polarity family is not a
single physical completion. There are eight transition-equivalent 14-state
polarity words, generated by A, C, and coupled F+I flips, plus eight D-flipped
12-state siblings.

The unresolved question was why the authored surface should use the all-slash
gauge origin.

Experiment 270 ranks all 16 recursively closed polarity words using only the
actual 3×3 artwork geometry and four simple locality costs:

- number of dot-exception stacks;
- number of orthogonal polarity boundaries;
- number of mixed physical rows;
- number of mixed physical columns.

The all-slash word is the unique zero-cost member under every measure. No
selector depth, recursion result, terminal payload, hidden state, or route table
is consulted.

This does not turn physical simplicity into new empirical evidence. It does,
however, make the authoring choice much less mysterious: the transition-visible
machine admits a three-bit polarity gauge, while the physical object chooses
the unique globally homogeneous representative of that gauge orbit.

Combined with Experiment 254, the result is especially compact. If Q4 is
authored with one shared exceptional-symbol polarity, the raw observations
force that symbol to slash. Experiment 270 shows that the same all-slash member
is also the unique minimum-complexity representative inside the broader closure
family discovered later.

The remaining Q4 polarity issue is therefore no longer "why this arbitrary
gauge origin?" but the narrower epistemic question of whether shared physical
polarity should be treated as an intended authoring grammar or merely the
simplest retrospective completion.
