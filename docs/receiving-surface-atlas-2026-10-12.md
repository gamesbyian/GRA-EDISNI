# INSIDE CE sticker: receiving-surface atlas (12 October 2026)

**Research mode: DISCOVER / DEVELOP.** This is a **candidate inventory**, not a list of detected CE receivers. Read together with [decoder-operation atlas](decoder-operation-atlas-2026-10-12.md) and [bridge tests](closed-corpus-reader-bridge-program-2026-10-12.md). A *consumer* is a surface, artifact, input, or process that could accept a derived instruction, selection, image or code and yield a checkable result. A historical authentic artifact is **not** proof that it accepts the stickers.

## Evidence and priority key

- **A** = source-anchored recipient: authentic input or artifact verified for the historical ARG, or direct connection from CE background. The alleged **CE-to-foreground** connection remains unproved.
- **B** = bounded/authentic artifact, candidate role not established.
- **C** = source needs acquisition or an invented role/parameter. Retain for adversarial exploration.
- **X** = an important *restricted prior failure* or source limitation; do not silently repeat the failed exact implementation.
- **T1** = investigate original object/bytes first; **T2** = candidate only after a native input cue; **T3** = speculative reserve. Tiers express **expected investigation yield**, not solution probability.

## Hard exclusions and warnings

1. **Actual available ≠ usable as CE recipient.** The true sticker-background → 534brn address gives R001–R014 special priority, but it does *not* validate any foreground-to-JPEG mapping. Website form history is verified for *earlier printer* answers, not CE.
2. **Static Terminal41 capture ≠ functioning input.** The preserved 72 textual page capture audit found no runnable submission form, and the 22-underscore viewgate is not an original live textbox. Reconstruct historical transport/offline response; do not send guessed passwords to public endpoints.
3. **No unique retail secret unlocked yet.** Steam beta/passwords and in-game dormant inputs have no identified CE acceptance witness. Investigate lawful local files, not live brute force.
4. **Avoid chronology reversal.** 2016 source objects are potential later destinations, but a 2020 Mac printer discovery cannot be assumed to be a 2019 CE instruction without evidence that the mechanism was available/anticipated.
5. **Do not treat X as whole-family refutation.** R023's fixed 74-address lookup, R053's *direct known* lever password, and R073's exact Xbox-row reuse are bounded negatives. Registered variations can remain hypotheses when their new operations are declared before reading output.
6. **Interchangeability matters.** Many of these are *the same surviving source* with different possible receiving functions, not 82 independent artifacts or 82 independent votes. The companion operation atlas deliberately tracks more abstract algorithms separately.
