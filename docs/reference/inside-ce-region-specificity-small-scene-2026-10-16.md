# INSIDE CE: frozen tiny-sticker and hard-negative challenge (16 October 2026)

**Mode: measured RESEARCH, not deployable classifier or new owner evidence.** The independent real-photo positive benchmark from [PR #303](inside-ce-independent-region-holdout-2026-10-16.md) localized **4/4 known large/frontal sticker papers** at IoU ≥ 0.60 in top eight. That does not test two crucial deployment questions: can this method find **small paper within a much wider scene**, and does it trigger on **ordinary sticker-like objects**?

## Method and predetermined test set

[Implementation](../../scripts/external_evidence/benchmark_sticker_region_stress.py) composes *source-pinned, independently photographed original physical sticker papers*, **039, 047, 063 and 118**, onto fixed **720 × 540** deterministic pseudo-collector tabletop scenes. Their source images and paper bounds are from the existing SHA-verified independent holdout register, disjoint from matching templates **003, 037, 038, 065, 125**. Ground-truth box positions are known exactly.

- **12 simulated positive images:** four real photo sticker-paper crops × paper occupying **1%, 3% and 8%** of the 720×540 output frame, with frozen positions and alternating 0°/90° rotation. These are synthetic *composites*, not new public original full-room photographs or independent physical acquisitions.
- **Four synthetic negatives:** cluttered desk with unrelated packaging, pale PS4-like product box, sticker-sized lettered paper label with a black bar, and numbered ticket bearing a black slash. All negatives are completely generated by code with no copy of a physical sticker. Hard decoys may be *semantically indistinguishable from an actual sticker by hash alone*; a false prompt is expected and must remain unverified.
- **Identical production proposal budget:** 1600 coarse regions, up to 1200 refined regions, top eight review boxes, original five templates at four 90-degree rotations. This benchmark deliberately **does not change** those parameters from the real-photo positive benchmark.
- **Metrics:** overlap ≥ IoU 0.40 at top eight, raw best IoU, all candidate scores and window-censoring details. Distance operating points **24/32/40/48/56/65** are frozen **before** reviewing outcomes. For each threshold, count positives with ≥1 localized region *under that threshold* and synthetic negatives with ≥1 misleading region. No new cutoff is selected or advertised as calibrated.
- **Audit:** new owner/sticker confirmations are **always zero**; hash reference template label can never be a read of a newly photographed serial. Failure to locate a crop, or false alarms on lookalikes, remains part of the published result.

**Interpretation constraint:** A false match on a generated blank scene is *not a measured real-world false-positive rate*. Even a true positive in a pasted-photo scene is *not measured recall on genuine small stickers photographed across a room*. These diagnostic cases are an intermediate falsifiable hurdle. The previous 4/4 large-paper result remains intact but cannot be extrapolated to this new domain.

## Already-known genuine public photographic negatives, no new acquisitions in CI

The repository already has a source-defined [public visual-source manifest](../../data/reference/inside-ce-visual-sources.json) containing **six exact SHA256-pinned** approved original media examples relevant to no-visible-sticker reviews: standalone PS4 product packshots and publisher promotional images, an iam8bit shipping screenshot, and the original [December 2019 owner open-box photograph](https://www.reddit.com/r/gamecollecting/comments/eaktdt/) already canonically **L08**. The open-box photograph documents no *visible numbered sticker* in that shot; it is **not** evidence the owner didn't possess the sticker at some earlier time.

[Original negative-control scorer](../../scripts/external_evidence/benchmark_sticker_region_real_negatives.py) runs **only when** the separate, existing explicit manual `CE visual provenance` workflow has fetched those permitted media files and `run_region_pilot=true`. It verifies their original exact SHA256; missing originals are **skipped with a reason**, never mistaken for a clean negative. It preserves up to eight apparent image-region hits and fixed threshold flags. This scan sends no additional network requests.

The standard PR CI **never fetches images**: it only executes the 16 synthetic cases and unit tests, then retains its result JSON for independent review.

## What would make us change the approach

This system makes spatial *suggestions* even for scenes without stickers. A useful autonomous detector would additionally need calibrated rejection, stronger object-boundary recognition and validated specificity on real independently photographed *sticker-free* CE/PS4 imagery. Choosing a hash threshold after observing these same test cases and declaring it accurate would be circular; any algorithm/threshold change must use a separate new heldout comparison, retaining this fixed benchmark as history.

We should not dispatch thousands of additional media searches solely because a visually similar object was returned. The meaningful economic metric is **cost and time per genuinely novel, canonical-reconciled original sticker photograph**, accounting for the rejected and unreviewed image budgets.

## First measured full stress run

The no-network [CI run 38959420837](https://github.com/gamesbyian/GRA-EDISNI/actions/runs/38959420837) at PR source SHA `9a26516f2c986a73a1668193a7fb081224892804` passed **143 tests** and executed all **12 positive** and **4 negative** synthetic scenes at the original unmodified scan/window budget.

- Without a rejection cutoff, **8/12** composite paper stickers had a top-eight suggested region overlapping the true paper box by IoU ≥0.40. The frozen **per-size breakdown** on exact-head [CI run 38959743068](https://github.com/gamesbyian/GRA-EDISNI/actions/runs/38959743068) was **1/4 at 1% of image area**, **3/4 at 3%**, and **4/4 at 8%**. Four pasted examples were missed, disproportionately at the tiniest scale. They are distinct source-photo stickers but **not** genuine wide-scene owner photographs.
- The system returned at least one suggested region for **4/4 synthetic sticker-free scenes**. These are proposed visual matches, not physical CE ownership claims.
- At **maximum hash distance 24**, it localized **1/12** of the positive scenes and still suggested a region for **1/4** negative scenes.
- At **maximum hash distance 32** (and at each tested larger cutoff through 65), it localized **8/12** positives and suggested a region for **4/4** negatives. None of the six frozen distance cutoffs simultaneously achieved good localization and low synthetic false prompting.
- These observations conclusively **do not justify autonomous sticker detection**. They do justify continued source-first human image review and researching discriminative sticker-specific features. A future improved method must have a separately frozen validation set; don't relabel these 16 studied examples as unseen.

The exact-source artifacts retain the full per-case boxes, distances and scan-window coverage. The original-source **real** negative images were **not** acquired or scanned in that PR check, so measured real-photograph specificity remains unknown.
