## 478: source-preservation receiver gates

- [Detailed report](experiment-478-source-native-consumer-affordances.md)
- [Source-bound artifact inventory](../data/experiment-478-source-native-consumer-affordances.json)

Fifteen individually documented original game, CE and Terminal41
surfaces are separated into verified functional historic inputs,
genuine outputs, static text, unexamined physical artifacts and
missing original binaries. The original known 14-command bunker
password cannot be read directly from the physical 81/27 sector split
without a new operation.

A contemporary **2016** thread about the unrecovered `SecretMap`
texture already suggested its possible fourteenth dot denotes the
large final secret orb. Any claimed new CE map marking must first
survive independently registered matching to the known fourteen
orb sites using native DDS/UV geometry.

The official iam8bit CE product listing also establishes art cards,
a foldout poster and spot-varnished packaging. This is not itself
an authorial clue. The already-active PR #159 independently shows a
publisher photo with nine concept sketches approximately arranged
3×3 on the poster. The independent CE vs standalone poster
identity and any A–I indexing remain unresolved. A December 2019
unboxing discussion describes **dozens** of concept cards rather
than source-confirming exactly nine; don't infer a nine-card codebook
from the sticker background count.

## 479: historically native lever class words

- [Detailed report](experiment-479-classword-lever-consumer.md)
- [Deterministic 324-master test](../scripts/audit_classword_lever_consumer.py)

The physical twelve-sticker A–I class words span the two foreground
alphabets, so in principle each class word could contain Up, Right
and Left under the independently historic sleeve mapping.
They nevertheless cannot reproduce the **already solved**
14-move bunker password in either natural order or reading
direction, **even under the weak 81 U/R + 27 U/L sector-alphabet
restriction alone**. All 28 password rotations/reversals and 108
cyclic starts fail. The 324 column-grammar/Q4 full-master
check independently agrees but adds no new premise to this negative.

This rules out one economical **existing-password replay**,
not a novel externally clued game input.
