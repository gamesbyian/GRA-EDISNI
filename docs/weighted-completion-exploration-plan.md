# Weighted completion exploration program

_Status: active, 4 Oct 2026._

## Purpose

The project now has enough structure to use the 43 missing H108 cells as a controlled **model ensemble** rather than as blank space.

The goal is not to guess one complete sticker sheet and decode it. The goal is to ask:

> Which operations produce the same or sharply constrained consequences across many coherent completions, and which attractive results exist only because one guessed completion happens to cooperate?

This program operationalizes Experiments 393–394.

## Canonical ensemble panels

Every exploratory operation should use the broadest relevant panels:

- **U2 / 648** — one-per-column 3/6 primary geometry + one-slash tail;
- **U3 / 216** — established primary polarity + exact POS3;
- **U4 / 20** — typed one-shot G5 closure;
- **U5 / 14** — recursive G6 incumbent family;
- **E2 / 2** — the externally selected `534brn` pair from Experiment 390;
- **R / frozen rival** — row-selector family when residues 84/102 or its operation family are relevant.

Do not substitute the per-residue modal prediction sheet for any of these panels.

## Core outputs for every probe

A sandbox experiment should report, where meaningful:

- number of distinct derived outputs per ensemble;
- invariant cells/tokens/features;
- survivor counts under an independently specified criterion;
- sensitivity to uncertain residues;
- whether U4 and U5 differ;
- whether E2 is unusually constrained;
- whether the result disappears when moving from a single completion to the ensemble;
- whether any apparent structure depends on a representation gauge.

A result may be interesting even when negative if it closes a cheap historically plausible operation family.

## Workstream A — external-consumer replay

Highest priority.

Use an operation only when another artifact supplies the key, subset, orientation, coordinate system, or consumer.

Examples:

- `534brn`-derived positional information;
- known Terminal41 selectors;
- CE cover / lever semantics if an independent traversal appears;
- printer-derived registration rules when the sticker carrier exposes an analogous physical channel.

Success criterion:

> the consumer removes a nontrivial fraction of a broad ensemble, or produces an invariant output across one ensemble but not its rivals.

## Workstream B — registration / check-bit structure

The PC printer establishes that sparse boundary marks can constrain ordering.

The sticker carrier may therefore be tested for **bounded, geometry-native registration metadata** without semantic image scoring.

Allowed initial probes:

- endpoint signatures of the native 12-cell A-I class words;
- fixed-width edge signatures;
- whether those signatures uniquely identify rows;
- whether A-I or solved physical order is unusually favored by edge continuity.

Do not search arbitrary subsets of cells for an ordering that looks good.

## Workstream C — lever consumer

The sleeve/lever mapping is historically grounded:

```
/ -> up
- -> right
. -> left
```

But direct serial-order replay of the known bunker password is structurally closed.

Reopen only when another artifact supplies:

- subset;
- traversal;
- start/end;
- ordering;
- command count.

Weighted completions can then tell us whether the resulting command stream is robust.

## Workstream D — coordinate / selector operations

The strongest recent progress came from treating marks as coordinates rather than symbols.

Allowed probes should use already licensed structures such as:

- DTMF row/column;
- physical row/column;
- native serial modulo-9 class;
- typed tail depth;
- previously frozen affine q gauges.

Exhaust the smallest coordinate-role family before adding any new transform.

## Workstream E — sensitivity and information maps

For any promising derived feature:

1. identify which unknown residues control it;
2. rank those residues by whether one observation would decide the feature;
3. cross-reference acquisition leads;
4. freeze the prediction before new imagery is inspected.

This connects speculative computation back to prospective physical evidence.

## Closed / prohibited sandbox behavior

Do not use the completion ensembles to justify:

- arbitrary row/column permutations chosen by semantic appearance;
- unconstrained image completion;
- OCR/word scoring across thousands of transforms;
- arbitrary ciphers;
- arbitrary cellular automata;
- multiplication of U5 support counts into pseudo-Bayesian probabilities;
- selecting whichever completion gives the nicest plaintext.

Computational cheapness is not evidentiary license.

## Graduation rule

A sandbox result graduates into the research queue only when at least one of these is true:

1. it is invariant over a broad coherent ensemble;
2. an independently specified consumer yields a sharp survivor reduction;
3. it separates two live model families prospectively;
4. it predicts a small set of physical residues whose future observation can falsify the result.

Otherwise record it as a negative or exploratory curiosity and move on.
